## Project Title

Equity Bank Database Management System

## Database Name

EQUITY_BANK_DB

## Description

This project is a PostgreSQL relational database designed for Equity Bank.

The database manages:

- Customers
- Branches
- Employees
- Bank Accounts
- Account Types
- Deposits
- Withdrawals
- Loans
- Loan Repayments
- Guarantors
- Collateral
- Bank Cards
- Mobile Banking
- Beneficiaries
- Fixed Deposits
- Insurance Policies
- Customer Complaints
- Branch Targets
- Currencies

## Features

- 20 relational tables
- Primary Keys
- Foreign Keys
- UNIQUE Constraints
- CHECK Constraints
- DEFAULT Constraints
- Referential Integrity
- Sample data (100+ records)
- SQL Queries
- Entity Relationship Diagram (ERD)

## Technologies Used

- PostgreSQL
- SQL
- Git
- GitHub
